During this project, i learned how to:
- Structure a layout using semantic HTML elements such as main and section
- Use Flexbox to separate content into two sections
- Create responsive layouts for desktop and mobile devices
- Use the picture element to display different images depending on the screen size
- Improve spacing and alignement using padding and gap
